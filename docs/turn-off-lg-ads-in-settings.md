# Turn off LG's built-in ads and tracking (no tools needed)

Do this first: it takes 5 minutes and works together with the DNS blocker.
Menu names differ slightly between webOS versions; use the Settings
search (magnifier icon) if a path doesn't match.

All of these are under **Settings (gear) → All Settings → General →
System → Additional Settings** (on older TVs: **General → About This TV
→ User Agreements**).

| Turn OFF | What it stops |
|---|---|
| **Live Plus** | Screen recognition (ACR) that tracks what you watch, even on HDMI |
| **Home Promotion** / **Content Recommendation** | Ad banners and "sponsored" tiles on the home screen |
| **Home Auto Launch** | The home bar popping up with ads at power-on |
| **Advertising → Limit Ad Tracking: ON** | Personalised ads |
| **Viewing Information**, **Interest-Based Recommendation**, **Voice Information** (in User Agreements) | Data sent to LG for ad targeting. Leave **Terms of Use** and **Privacy Policy** accepted, or apps and the store stop working |

Also useful:
- **General → Devices → TV Management / Home Settings**: turn off
  "Recommended" / "Sponsored" rows if your model shows them.
- **Support → Software Update → Auto Update: OFF** only if a new update
  brings back ads you removed. Leaving updates on is safer for security.
